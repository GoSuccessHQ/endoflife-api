# Documentation

One page per area of the API, as the specification groups its operations:

- [Index](index.md): the main endpoints (`index()`)
- [Products](products.md): products, release cycles and their support dates (`$eol->products`)
- [Categories](categories.md): products by category (`$eol->categories`)
- [Tags](tags.md): products by tag (`$eol->tags`)
- [Identifiers](identifiers.md): purl, cpe and repology identifiers (`$eol->identifiers`)

[README](../README.md#error-handling).
